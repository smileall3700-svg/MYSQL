# Store Management System (MySQL)

A relational inventory and tracking system built to support real-time stock decisions.

## What's here
- `01_schema.sql` — table structure and relationships
- `02_sample_data.sql` — sample records for testing queries
- `03_dashboard.html` — lightweight dashboard view of the data

## Why I built it
Practicing schema design and query writing for inventory/stock-level scenarios — 
the kind of data structuring a PM needs to read and query independently.
